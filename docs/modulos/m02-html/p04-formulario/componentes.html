Esta página reúne los elementos HTML que utiliza el sitio. De cada uno se muestra como se ve, su código y, cuanto hace falta, una nota.

Texto

Encabezados <h1> a <h6>

Estructuran el contenido en niveles jerárquicos para organizar el índice y facilitar la lectura..

Encabezado de nivel 4

Encabezado de nivel 5
Encabezado de nivel 6
<h4>Encabezado de nivel 4</h4>
<h5>Encabezado de nivel 5</h5>
<h6>Encabezado de nivel 6</h6>

Buena práctica: No saltes niveles para conseguir un tamaño de letra; el tamaño lo decide el CSS. Los lectores de pantalla usan los encabezados para navegar.

Párrafos<p> y salto de línea<br>

Los párrafos son bloques de texto que se separan con un espacio en blanco. Se usan para organizar el contenido y facilitar la lectura.

Clinica Veterinaria ConSentidos

Lunes a viernes: 8:00 a.m. a 6:00 p.m.
Sábados: 8:00 a.m. a 12:00 m.
Urgencias: las 24 horas por teléfono. 

<p>Clinica Veterinaria ConSentidos.</p>

<p>Lunes a viernes: 8:00 a.m. a 6:00 p.m.</br>
<p>Sábados: 8:00 a.m. a 12:00 m.</br>
<p>Urgencias: las 24 horas por teléfono.</p>

Buena práctica: no uses varios <br> seguidos para separar los bloques; separa con párrafos y deja el espacio al CSS.

Énfasis en el texto <em> y fuerte <strong> y resaltado <mark>

El énfasis se usa para dar importancia a ciertos fragmentos de texto.

La vácuna antirrábica es obligatoria cada año. El resto del plan depende de la edad y de si la mascota sale a la calle. Si llegas con retraso de más de un mes, el plan sí se reinicia: no es un trámite, es lo que hace que la vacuna proteja. 

<p>
La vácuna antirrábica es <strong>obligatoria</strong> cada año. El resto
del plan depende de la edad y de si la mascota sale a la calle. Si llegas
con retraso de más de un mes, el plan <em>sí</em> se reinicia: no es un 
trámite, es lo que hace que la vacuna proteja.</p>

Buena práctica: Usa <strong> para indicar importancia seria o urgencia y <em> para cambiar el énfasis de la oración. No los uses solo para cambiar el aspecto visual

Código <code> y texto preformateado <pre>

La etiqueta <code> marca fragmentos cortos de código en línea dentro de un párrafo, mientras que <pre> conserva exactamente los espacios, tabulaciones y saltos de línea del texto tal como fueron escritos.

Para programar una cita, envía el parámetro servicio=consulta en la solicitud.

<p>Clínica Veterinaria ConSentidos.</p>
Lunes a viernes: 8:00 a.m. a 6:00 p.m.<br>
Sábados: 8:00 a.m. a 12:00 m.<br>
Urgencias: las 24 horas por teléfono.
<p>Para programar una cita, envía el parámetro <code>servicio=consulta</code>
en la solicitud.</p>

<pre><code>&lt;p&gt;Clínica Veterinaria ConSentidos.&lt;/p&gt;
    Lunes a viernes: 8:00 a.m. a 6:00 p.m.&lt;br&gt;
    Sábados: 8:00 a.m. a 12:00 m.&lt;br&gt;
    Urgencias: las 24 horas por teléfono.</code></pre>

Buena práctica: Para mostrar bloques de código de varias líneas, anida siempre <code> dentro de <pre> y escapa los símbolos < como &lt; y > como &gt; para que el navegador los muestre como texto y no los ejecute como etiquetas HTML.

Fechas y horas <time>

Representa un periodo específico en el tiempo o una fecha en un formato legible tanto para humanos como para navegadores y buscadores mediante el atributo datetime.

Última actualización: 15 de noviembre de 2026. 

<p>
    Última actualización:
    <time datetime="2026-10-22">15 de noviembre de 2026</time>.
</p>

Buena práctica: Incluye siempre el atributo datetime con el formato estándar internacional (AAAA-MM-DD) y asegúrate de que coincida exactamente con la fecha visible en el texto.

Listas

Listas ordenadas <ol>

Organizan elementos en una secuencia numérica o secuencial donde el orden importa.

  1. Registro en recepción y revisión del carné.
  2. Triaje
    1. Peso en báscula.
    2. Temperatura.
  3. Consulta con el veterinario.
  4. Indicaciones por escrito y próxima cita.
<ol>
    <li>Registro en recepción y revisión del carné. </li>
        <li>
            Triaje
            <ol type="a">
                <li>Peso en báscula.</li>
                <li>Temperatura.</li>
            </ol>
        </li>
        <li>Consulta con el veterinario.</li>
    <li>Indicaciones por escrito y próxima cita.</li>
</ol>

Buena práctica: Utiliza listas ordenadas (<ol>) exclusivamente cuando la secuencia o el orden de los pasos altere el resultado (como los protocolos clínicos). Para sub-niveles, puedes emplear el atributo type o CSS para variar el estilo de numeración sin romper la jerarquía.

Listas no ordenadas <ul>

Organizan elementos sin un orden específico, donde el orden no es importante.

  • Inicio
  • Servicios
  • Guía de componentes
  • Página de prueba
<ul>
    <li><a href="URL.example">Inicio</a></li>
    <li><a href="URL.example">Servicios</a></li>
    <li><a href="URL.example">Guía de componentes</a></li>
    <li><a href="URL.example">Página de prueba</a></li>
</ul>

Buena práctica: Utiliza listas no ordenadas (<ul>) exclusivamente cuando el orden de los elementos no sea relevante (como las características de un producto). Para sub-niveles, puedes emplear el atributo type o CSS para variar el estilo de numeración sin romper la jerarquía.

Listas de descripción <dl>, <dt> y <dd>

Crean glosarios o pares de clave y valor. La etiqueta <dl> abre la lista, <dt> define el término y <dd> aporta su descripción.

Desparasitación
Tratamiento que elimina parásitos internos y externos.
Microchip
Dispositivo del tamaño de un grano de arroz, con un código que identifica a la mascota si se pierde.
Triaje
Revisión inicial que determina la urgencia de la atención.
<dl>
    <dt>Desparasitación</dt>
        <dd>Tratamiento que elimina parásitos internos y externos.</dd>

    <dt>Microchip</dt>
        <dd>Dispositivo del tamaño de un grano de arroz, con un código que 
            identifica a la mascota si se pierde.
        </dd>

    <dt>Triaje</dt>
        <dd>Revisión inicial que determina la urgencia de la atención.</dd>
<dl>

Buena práctica: Utiliza el elemento <dl> específicamente para agrupaciones de términos y descripciones, como glosarios, metadatos o pares de clave-valor. Evita usarlo para maquetar listas de elementos simples o columnas visuales cuyo contenido no guarde una relación conceptual de definición.

Enlaces

Enlaces internos<a>

Los enlaces se crean con la etiqueta <a> y el atributo href para especificar la dirección del enlace.

  • Inicio
. 
<li><a href="index.html">Inicio</a></li>

Buena práctica: Escribe siempre textos de enlace descriptivos que indiquen claramente el destino (evita textos genéricos como "haz clic aquí" o "leer más").

Enlaces externos<a>

Los enlaces se crean con la etiqueta <a> y el atributo href para especificar la dirección del enlace.

Ministerio de Desarrollo Agropecuario . 
<a href="https://www.mida.gob.pa" target="_blank" rel="noopener noreferrer">
    Ministerio de Desarrollo Agropecuario
</a>

Buena práctica: Escribe siempre textos de enlace descriptivos que indiquen claramente el destino (evita textos genéricos como "haz clic aquí" o "leer más"). Para enlaces externos que se abren en una pestaña nueva con target="_blank", agrega siempre rel="noopener noreferrer" por seguridad, y usa enlaces internos con #id para facilitar la navegación rápida.

Enlaces de descarga<a download>

Los enlaces se crean con la etiqueta <a> y el atributo href para especificar la dirección del enlace.

Descargar la guía de vacunación (PDF) 
<a href="assets/docs/guia-vacunacion.pdf" download>
    Descargar la guía de vacunación (PDF)
</a>

Buena práctica: Indica siempre en el texto del enlace el formato y, de ser posible, el peso del archivo (por ejemplo, (PDF)) para que el usuario sepa qué va a descargar. Ten en cuenta que el atributo download solo funciona con archivos del mismo origen (tu propio servidor) y permite sugerir un nombre de archivo personalizado si se le asigna un valor, como download="guia.pdf".

Enlaces de contacto mailto: y tel:

Los enlaces de contacto se crean con la etiqueta <a> y los atributos href con los prefijos mailto: para correos electrónicos y tel: para números de teléfono.

info@ejemplo.com
+34 911 23 45 67 
<a href="mailto:info@ejemplo.com">info@ejemplo.com</a>
<a href="tel:+34911234567">+34 911 23 45 67</a>

Buena práctica: Utiliza los prefijos mailto: y tel: para crear enlaces de contacto que permitan a los usuarios enviar correos electrónicos o llamar por teléfono con un solo clic.

Imágenes y multimedia

Imágenes <img> y <figure>

La etiqueta <img> inserta imágenes en la página, mientras que <figure> y <figcaption> permiten acompañarlas con una leyenda explicativa.

<img src="assets/img/logo-consentidos.svg" alt="Logo de la Clínica Veterinaria ConSentidos" width="64" height="64">

<figure>
    <img src="assets/img/luna.svg"
         alt="Ilustración de Luna, una gata gris atigrada, sentada"
         width="320" height="240" loading="lazy">
    <figcaption>Luna, paciente del mes.</figcaption>
</figure>

Buena práctica: Incluye siempre alt para describir la imagen sin repetir el texto de <figcaption>, especifica width y height para evitar saltos en el diseño, y usa loading="lazy" para diferir la descarga de imágenes fuera de pantalla.

Audio <audio>

Permite incrustar contenido de sonido en el documento con controles de reproducción nativos y fuentes alternativas.

Tono de recordatorio de citas:

<p id="etq-audio">Tono de recordatorio de citas:</p>
<audio controls preload="metadata" aria-labelledby="etq-audio">
    <source src="assets/media/recordatorio.mp3" type="audio/mpeg">
    Tu navegador no reproduce audio.
    <a href="assets/media/recordatorio.mp3">Descarga el tono</a>.
</audio>

Buena práctica: Usa preload="metadata" para cargar solo la duración y datos básicos sin consumir ancho de banda innecesario, vincula una etiqueta descriptiva con aria-labelledby y ofrece siempre un enlace de descarga de respaldo dentro de <audio>.

Video con subtítulos <video> y <track>

Incrusta reproductores de video con soporte para múltiples formatos, imagen de portada y pistas de subtítulos accesibles.

<video controls width="640" height="360" preload="metadata"
       poster="assets/media/consejos-poster.jpg">
    <source src="assets/media/consejos.webm" type="video/webm">
    <source src="assets/media/consejos.mp4"  type="video/mp4">
    <track kind="subtitles" src="assets/media/consejos-es.vtt"
           srclang="es" label="Español" default>
    Tu navegador no reproduce video.
    <a href="assets/media/consejos.mp4">Descarga el video</a>.
</video>

Buena práctica: Define siempre width, height y una imagen poster para reservar el espacio visual antes de reproducir[cite: 5]. Incluye múltiples formatos con <source> (como WebM y MP4) y añade pistas de subtítulos con <track> para garantizar la accesibilidad.

Contenido incrustado

Marco incrustado de página propia <iframe>

Permite incrustar otra página HTML perteneciente al mismo sitio web dentro del documento actual.

<iframe src="paginas/test.html"
        title="Página de prueba del sitio de ConSentidos"
        width="600" height="240" loading="lazy"></iframe>

Buena práctica: Incluye siempre un atributo title descriptivo porque es obligatorio para que los lectores de pantalla identifiquen el contenido del marco. Además, define width, height y loading="lazy" para reservar el espacio y diferir su carga hasta que sea visible.

Marco incrustado de terceros <iframe>

Incrusta contenido externo (como mapas o reproductores) aplicando restricciones de seguridad para proteger la página.

<iframe src="https://www.openstreetmap.org/export/embed.html?bbox=-
80.9950%2C8.0900%2C-80.9650%2C8.1100&amp;layer=mapnik"
        title="Mapa de Santiago de Veraguas, donde está la clínica"
        width="600" height="340" loading="lazy"
        referrerpolicy="no-referrer"
        sandbox="allow-scripts"></iframe>

Buena práctica y seguridad: En contenido de terceros, usa referrerpolicy="no-referrer" para no enviar la dirección de tu página al sitio incrustado y restringe permisos con sandbox habilitando solo lo indispensable (como allow-scripts). Nunca combines allow-scripts con allow-same-origin en contenido ajeno, ya que juntos anulan el aislamiento de seguridad.

Documento incrustado <object>

Incrusta documentos externos como archivos PDF directamente en la página, incluyendo contenido alternativo en su interior.

<object data="assets/docs/guia-vacunacion.pdf"
        type="application/pdf" width="600" height="400">
    <p>Tu navegador no muestra PDF.
        <a href="assets/docs/guia-vacunacion.pdf">Descarga la guía</a>.</p>
</object>

Buena práctica: Especifica siempre el tipo de archivo en type (application/pdf), define width y height para evitar saltos visuales, e incluye un enlace de descarga alternativo dentro de <object> para navegadores que no puedan renderizar el PDF.

Elementos interactivos

Preguntas frecuentes / Acordeón <details> y <summary>

Permiten crear bloques de contenido desplegables de forma nativa sin necesidad de escribir JavaScript.

¿Cada cuánto debo desparasitar a mi perro?

Cada tres meses, con la dosis que indique el veterinario.

¿Necesito cita para vacunar?

Sí. Así preparamos la vacuna y revisamos antes su carné.

<details name="preguntas">
    <summary>¿Cada cuánto debo desparasitar a mi perro?</summary>
    <p>Cada tres meses, con la dosis que indique el veterinario.</p>
</details>

<details name="preguntas">
    <summary>¿Necesito cita para vacunar?</summary>
    <p>Sí. Así preparamos la vacuna y revisamos antes su carné.</p>
</details>

Buena práctica: Asigna el mismo atributo name a varios elementos <details> relacionados para convertirlos en un acordeón exclusivo donde abrir uno cierra automáticamente los demás. Usa siempre un <summary> claro y descriptivo como primer hijo.

Medidor de rango <meter>

Representa una medida escalar dentro de un rango conocido, como el peso saludable de una mascota frente a valores mínimos, máximos y óptimos.

4,2 kg 4,2 kg (rango saludable: 3 a 5 kg) 

<p>
    <label for="peso-luna">Peso de Luna</label>
    <meter id="peso-luna" min="0" max="8" low="3" high="5"
           optimum="4" value="4.2">4,2 kg</meter>
    4,2 kg (rango saludable: 3 a 5 kg)
</p>

Buena práctica: Reserva <meter> exclusivamente para magnitudes dentro de un rango conocido (never para el avance de una tarea). Define los umbrales low, high y optimum para que el navegador aplique automáticamente el código de color semántico, y asócialo siempre a un <label>.

Barra de progreso <progress> y <output>

Muestra el avance de una tarea que tiene un inicio y un final definidos, acompañado de su salida textual y botones de control.

2 de 5 dosis 2 de 5 dosis 

<p>
    <label for="plan-vacunas">Plan de vacunación de Max</label>
    <progress id="plan-vacunas" value="2" max="5">2 de 5 dosis</progress>
    <output id="plan-texto" for="plan-vacunas">2 de 5 dosis</output>
</p>

<button type="button" id="btn-dosis">Registrar una dosis</button>
<button type="button" id="btn-reiniciar" hidden>Reiniciar el plan</button>

Buena práctica: Utiliza <progress> únicamente para representar el grado de finalización de un proceso (como dosis aplicadas o carga de archivos). Incluye texto alternativo dentro de la etiqueta para lectores de pantalla y vincula el elemento <output> mediante el atributo for.
